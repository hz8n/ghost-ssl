## Install (10s)
```bash
git clone https://github.com/hz8n/ghost-ssl.git
cd ghost-ssl
chmod +x ghost-ssl.py
./ghost-ssl.py --help
./ghost-ssl.py --target 127.0.0.1 --output report.json
```
